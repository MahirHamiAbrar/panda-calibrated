# Change Log

All notable changes to the "panda-calibrated" extension will be documented in this file.

## [1.0.0] - 2026-09-14

### Added
- Initial release of **Panda Calibrated**.
- Full LSP Semantic Token Highlighting support matching the depth of VS Code's Dark Modern.
- Calibration of all syntax roles:
  - Modules & Namespaces in **Panda Lavender** (`#B084EB`).
  - Classes, Interfaces, and Type Annotations in **Golden Peach** (`#FFCC95`).
  - Function declarations and free calls in **Sky Blue** (`#6FC1FF`).
  - Method invocations and builtins in **Electric Cerulean** (`#45A9F9`).
  - Parameters, Keyword Arguments, and Constants in **Warm Apricot** (`#FFB86C`).
  - Variables, Router Instances, and Imported Identifiers in **Panda Ice Blue** (`#9CDCFE`).
  - Object Properties and Fields in **Soft Rose** (`#FF9AC1`).
  - String literals in **Neon Mint** (`#19F9D8`) and Docstrings in **Sage Mint** (`#7BE6A9`).
  - Full support for Python, TypeScript, JavaScript, Go, Rust, C++, HTML/CSS, JSON, Markdown, and Git Diffs.
